## Spy Game

Игра «Шпион» — была недавно популярна в тик-ток, реализованная как веб-приложение. Игроки получают секретные роли, у шпионов задача вычислить слово, у игроков говорить максимально похожие слова не выдав смысла.

## Возможности

    Система тем — предустановленные паки слов по доте + предпросмотр тем

    Загрузка своих тем — выбор файла через input

    Режим предпросмотра — просмотр тем перед началом игры, поддерживает предосмотр пользовательских тем

    Настройки игры — можно добавить любое количество игроков, любое количество шпионов + rand для случайного количества. Функция сохранения настроек

## Быстрый старт

  Клонируйте репозиторий:

    git clone https://github.com/pron1xxx/spy-game.git
    cd spy-game

  Запустите локальный сервер (например, через Python):
  
      python -m http.server 8000
  или через VS Code Live Server.

  Откройте в браузере:
  
    http://localhost:8000

  Проект не требует сборки или установки зависимостей — это статическое веб-приложение.
  Можно зайти в онлайн версию на github-pages этого репозитория

  ## Технологии

    HTML5 — разметка экранов
    Vanilla JavaScript — вся игровая логика
    CSS — стилизация интерфейса
    JSON — формат паков данных
